# Screencast scripts for Meta App Review (S3, 26 Nov 2026 — for Ahmed to record)

Three videos, each under 3 minutes. Only Ahmed's own test accounts appear — his personal Instagram and Facebook accounts
(app roles), marked «حساب تجربة» in «إعدادات المساعد» → «السوشيال». **No real guest may appear on screen**: before each
recording open «المحادثات» with the filter «انستجرام» / «ماسنجر» and the search on the test account's name, so the list
shows only the test conversations. Meta's reviewers do not read Arabic: the English labels below are what each step must
make visible — as an on-screen caption (CapCut → Text), **never as narration: Meta asks for no audio**, 1080p or better,
screen width ≤ 1440, an enlarged cursor, the mouse rather than the keyboard (`review-items.md` §1). Each permission needs a
recording: upload the same video on every item it covers and give the seconds of each step in the item's text.

How to record:
- iPhone: Settings → Control Center → add «Screen Recording»; swipe down → the record button; stop from the red pill.
- Windows: Win + Alt + R (Xbox Game Bar) starts and stops; the file is in Videos → Captures.
- Join the phone part and the computer part in one file (CapCut, or upload two files if the form allows more than one).
